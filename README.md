# PIKATILFLAY Bet

O PIKATILFLAY Bet é um simulador de apostas que fiz para brincar com a ideia de tentar a sorte. A página começa com R$ 10.000,00 de saldo fictício e permite escolher um valor para apostar. A cada rodada, o resultado é sorteado entre vitória e derrota, e o saldo muda de acordo com o valor escolhido.

O site mostra mensagens diferentes para cada resultado e tem alguns efeitos visuais para acompanhar as rodadas. Também dá para fazer uma aposta apertando Enter no campo de valor.

## Tecnologias utilizadas

Usei HTML, CSS e JavaScript, além das fontes do Google Fonts e dos ícones do Font Awesome.

## Como abrir

Baixe os arquivos do repositório e abra o `index.html` no navegador. Não precisa instalar nada. Para carregar as fontes e os ícones externos, é necessário ter conexão com a internet.

## Arquivos

- `index.html`: estrutura da página.
- `style.css`: visual, cores e animações.
- `script.js`: saldo, validação das apostas, sorteio dos resultados e interações.

É só um simulador, sem apostas com dinheiro real. O saldo é fictício e fica na página enquanto ela estiver aberta.
